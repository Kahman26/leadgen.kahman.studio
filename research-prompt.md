# Промпт для автопроверки объектов через Claude Code

Вставить в новую сессию Claude Code, где доступен поиск в интернете.
Категорию менять в двух местах — они отмечены.

---

Ты работаешь с сервисом подбора лидов **leadgen**. Задача: проверить в интернете
каждый объект категории **«База отдыха»** и записать найденное в базу.

## Доступ к серверу

```bash
ssh -i C:/Users/User10/.ssh/injector-master/id_ed25519 -o IdentitiesOnly=yes root@130.49.146.66
```

Код лежит в `/opt/leadgen`, база — в `/var/lib/leadgen/leads.db`.
Все команды выполняй через пользователя `leadgen`:

```bash
ssh -i C:/Users/User10/.ssh/injector-master/id_ed25519 -o IdentitiesOnly=yes root@130.49.146.66 \
  'sudo -u leadgen /opt/leadgen/venv/bin/python /opt/leadgen/research_cli.py <команда>'
```

## Порядок работы

**1. Получи список объектов** (здесь меняется категория):

```bash
... research_cli.py list "База отдыха"
```

Вернётся JSON: `id`, название, сайт, состояние сайта, телефон, балл.
Объектов около 25 — это нормально, иди по ним по очереди.

**2. По каждому объекту, по одному за раз:**

а) Возьми готовый запрос с данными объекта:

```bash
... research_cli.py brief 264
```

б) Выполни по нему **поиск в интернете**. Ищи на русском, пробуй разные
формулировки: название + Екатеринбург, название + «база отдыха», название +
«официальный сайт», название + «забронировать».

в) Собери ответ **строго по схеме из запроса** — один объект JSON.

г) Запиши результат. JSON положи в локальный файл и передай на stdin —
так кириллица и кавычки не пострадают:

```bash
ssh -i C:/Users/User10/.ssh/injector-master/id_ed25519 -o IdentitiesOnly=yes root@130.49.146.66 \
  'sudo -u leadgen /opt/leadgen/venv/bin/python /opt/leadgen/research_cli.py apply 264' < found.json
```

Команда ответит, что записалось: новый статус, сайт, прежний адрес, балл.

**3. В конце — короткий отчёт:** сколько проверено, у скольких нашёлся другой
действующий сайт, сколько закрылось, по скольким ничего не нашлось.

## Правила — они важнее скорости

- Пиши **только то, что реально видел** в результатах поиска. Ничего не
  достраивай по смыслу и не угадывай по названию.
- На каждый факт — **ссылка**, откуда он взят.
- Не нашёл — ставь `null` или пустой список. Это нормальный ответ, он лучше
  выдуманного. По выдуманному телефону будут звонить живому человеку.
- Телефон и почту бери со страниц самого бизнеса или его карточек на
  площадках бронирования, а не из сомнительных справочников.
- Соцсети компании — это **не** личные контакты руководителя.
- Если объектов с похожим названием несколько — не выбирай наугад. Отметь
  это в `status_note` и оставь спорные поля пустыми.

## Чего делать не надо

- **Не меняй базу напрямую** запросами SQL. Только через `research_cli.py apply` —
  он сохраняет правила: контакты ложатся лишь в пустые поля, исправленное
  руками не трогается, адрес сайта меняется только если рабочего нет.
- **Не трогай другие категории** — работай строго по выданному списку.
- Не перезапускай сервис и не меняй конфиги.
- Если команда вернула ошибку — покажи её и остановись, не обходи стороной.

## Что произойдёт с объектом

Найденное попадёт в поля `ai_*` и покажется в карточке блоком «Что нашёл
Claude» со списком источников. Статус сменится с «Новый» на **«Автопроверка»** —
это значит, что данные найдены, но человеком ещё не сверены.
